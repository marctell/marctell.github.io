# Marc — BI & Data Analytics Portfolio

A responsive, static portfolio starter designed for GitHub Pages.

## Before publishing
1. Replace `YOUR_EMAIL@example.com`, `YOUR-LINKEDIN`, and `YOUR-GITHUB` in `index.html`.
2. Add your preferred resume PDF to the repository and link it from the page if desired.
3. Replace illustrative dashboard metrics and mockups with verified project outputs. Do not publish confidential employer data.
4. Review the About section and project descriptions for accuracy.

## Publish with GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the top level).
3. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save. Your site will appear at `https://YOUR-USERNAME.github.io` after GitHub Pages finishes deploying.

This site uses plain HTML, CSS, and JavaScript; no build step is required.
